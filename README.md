# Atrium Gateway

OpenAI 协议转发网关

Atrium Gateway 是部署于服务器端的 HTTP 网关，位于调用方与上游 OpenAI 兼容端点之间。调用方以 OpenAI 兼容协议访问网关；网关校验其 `Authorization` 中的账号密钥，通过后把请求转发至所选上游端点，并原样返回响应。该过程对调用方透明，客户端无需更换 SDK 或调整协议风格。

## 设计目标

- NativeAOT
- 协议透明转发
- 受控内容改写
- 网关鉴权
- 被动故障转移

## 技术细节

- 网关仅承担转发职责。路由、负载均衡、模型映射与协议转换不在其范围内；上游切换仅为被动故障转移，不探测、不均衡、不跨重启保存可用性。
- TLS 由前置代理终止，网关自身只监听 HTTP。

## 受控改写清单

| 改写项 | 规则 |
|---|---|
| 上游地址 | 替换为所选上游的 baseUrl；`Host` 随该项派生 |
| `Authorization` | 校验调用方账号密钥，通过后丢弃其取值，注入所选上游的密钥 |
| `User-Agent` | 替换 |
